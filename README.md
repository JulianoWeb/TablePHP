# Formulário PHP 📝

Formulário simples feito em PHP.

## Funcionalidades

* Campo para nome
* Campo para e-mail
* Validação do e-mail
* Exibe o IP do visitante
* Mensagens de erro e sucesso

## Como usar

Coloque o arquivo em um servidor PHP, como o XAMPP, Apache ou PHP embutido.

Com o PHP instalado:

```bash
php -S localhost:8000
```

Depois acesse:

```text
http://localhost:8000
```

## Tecnologias

* PHP
* HTML
* CSS
